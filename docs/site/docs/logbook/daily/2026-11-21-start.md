## Kaizen

- **Show how long a failure has been red.** Each check compares a run only
  with the one before it, so a failure red for ten nights looks the same as
  one red since yesterday. The failed-runs and automation-PR checks should
  count consecutive red nights.
- **Mechanize the failed-runs check.** It ran the same per-repo run list
  across 33 repos, then per-run and per-job log reads; a run with many jobs
  cannot return its failed logs in one call. It is the next candidate for a
  `vrg-*` tool (history, `vergil-project/.github#1317`).
- **The user identity cannot see what a security record needs.** It cannot
  read Dependabot alerts or a run's artifacts, so one record was created
  without naming the package. The review needs a sanctioned way to read
  them.
- Nightly sync PRs that close and reopen hide their real age; the checks
  should report the age of the failure, not of the PR.
